# 🤖 MarketMind — 多 Agent 协作市场研究系统

> 自动化行业研究报告生成工具，由三个专职 Agent 协作完成从信息检索到报告输出的全流程。

---

## 📌 项目背景

传统市场研究依赖人工检索、逐篇阅读、手动汇总，一份完整报告往往需要数小时甚至数天。  
**MarketMind** 通过多 Agent 分工协作，将这一流程压缩至 **10 分钟以内**，信息覆盖量是人工的 5 倍以上。

---

## 🧠 系统架构

```
用户输入研究主题
        │
        ▼
┌─────────────────┐
│   Search Agent  │  ← 关键词拆解 + 多源信息并发检索
└────────┬────────┘
         │ 原始资料
         ▼
┌─────────────────┐
│ Analysis Agent  │  ← 长链推理、趋势提炼、矛盾信息校验
└────────┬────────┘
         │ 结构化分析结果
         ▼
┌─────────────────┐
│  Report Agent   │  ← 报告生成、格式化输出（Markdown/PDF）
└─────────────────┘
```

### Agent 分工说明

| Agent | 职责 |
|-------|------|
| **Search Agent** | 将研究主题拆解为多维关键词，并发检索行业资讯、竞品动态、市场数据 |
| **Analysis Agent** | 对原始内容进行多步推理，提炼核心趋势，识别机会与风险，校验矛盾信息 |
| **Report Agent** | 整合分析结果，生成带结论与数据支撑的完整研究报告 |

---

## ⚙️ 技术栈

- **语言**：Python 3.10+
- **LLM**：Claude API（`claude-sonnet-4-20250514`）
- **Agent 通信**：基于任务队列的异步消息传递
- **输出格式**：Markdown / 控制台日志

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your-username/marketmind.git
cd marketmind
```

### 2. 安装依赖

```bash
pip install anthropic
```

### 3. 配置 API Key

```bash
export ANTHROPIC_API_KEY="your-api-key-here"
```

### 4. 运行

```bash
python main.py
```
